# 創新與第一性思維 — innovation

核心來源：Ozan Varol（Think Like a Rocket Scientist）

## 核心概念

**第一性原理思考**
回到最基本的真實，質疑所有假設，拒絕「一直以來的做法」。
區分：什麼是真實的限制？什麼是你沒有質疑過的假設？

**面對未知的勇氣**
承認「我不知道」是創新的起點，不是弱點。
大多數「聰明」的決策失敗，是因為決策者不允許自己說不知道。

**視角轉換**
把問題反過來看：不是「如何贏得這場比賽」，是「如何重新定義這場比賽」。
最強的創新往往不是解決問題，而是讓問題消失。

**失敗學習哲學**
每次失敗 = 一個數據點。火箭科學家不說「失敗了」，說「我們得到了數據」。
但這不是為失敗辯護——是把失敗系統化，讓它有用。

**約束轉化優勢**
資源限制不是障礙，是設計約束。
最聰明的解法往往來自「在這個限制下，什麼是可能的？」而非「如何移除這個限制」。

**系統性思考方法**
建立可重複的問題解決流程，而非每次靠直覺。
單次靠直覺成功 ≠ 方法有效。可複製才算數。

## 寫作觸發

**最適引擎：A（拆解思維框架）或 B（挑戰「我在創新」的自我認知）**

A 用法：
- 拆解第一性原理的五個步驟：假設清單 → 質疑每個 → 找出哪些是真實限制 → 重建 → 測試
- 框架：「你的業務有多少是假設，多少是事實？」

B 用法：
- 金句：「你以為的限制，只是你沒有質疑過的假設。」
- 金句：「大多數『創新』只是把舊做法換了個名字。」
- 逼選擇：繼續在現有框架裡優化，或重新質疑框架本身

LinkedIn 首句範例：
- 「Most 'innovation' is just optimization. Real innovation questions whether the problem needs to exist.」
- 「你以為是限制的，90% 是沒有被質疑過的假設。」

**最適主題：創業策略、產品設計、商業模式創新、「我們一直這樣做」的場景**
