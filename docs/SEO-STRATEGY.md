# SEO Strategy v0.1

## 定位

- 網站：Chao's Brain
- 正式網址：https://angepasstlab.com
- 主要語言：繁體中文
- 主要市場：台灣、德國、美國的跨境製造業市場
- 核心讀者：製造業經營者、B2B 決策者、跨境供應鏈參與者與工業科技創業者
- 商業目標：增加非品牌自然搜尋曝光、有效閱讀與具體合作詢問

## 唯一 Goal

每週找出五個有價值的內容機會，選出一個最值得處理的主題，經人工事實確認後發布或更新至少一篇內容，並持續增加非品牌自然搜尋曝光、有效流量及商業轉換。

## 主題權威範圍

1. 跨境製造與供應鏈：台灣、德國、美國之間的採購、交付、在地化與風險。
2. 工具機與精密製造：設備、加工、產能、品質、服務與市場結構。
3. B2B 策略：切換成本、信任、通路、品牌、併購與中小企業競爭。
4. 工業 AI 與自動化：應用價值、組織設計、導入限制與護城河。
5. 經營決策：投資、風險、創業與跨文化市場判斷。

## Pillar／Cluster／Spoke

| Pillar | Cluster 範例 | Spoke 範例 |
|---|---|---|
| 跨境製造 | 美國再工業化、德國 Mittelstand、台灣供應鏈 | 採購盲點、交付風險、關稅、在地服務 |
| 工具機與精密加工 | CNC、五軸、航太、鈦合金 | 訂單週期、產能、設備選型、品牌整合 |
| B2B 成長策略 | 信任、切換成本、通路、品牌 | 客戶獲取、售後、併購、差異化 |
| 工業 AI | 視覺檢測、工作流、組織角色 | ROI、資料限制、導入失敗、治理 |

Pillar 頁面是否需要新建，必須依 Search Console 與既有內容盤點後另行批准；v0.1 不自動建立公開頁面。

## 搜尋意圖

- Informational：理解市場、技術、風險或策略。
- Comparative：比較供應鏈、區域、方案或商業模式。
- Decision-support：協助採購、投資、導入與經營決策。
- Commercial investigation：有合作、顧問或供應需求前的研究。

內容優先處理能連結第一手跨境製造經驗、具體決策問題及商業目標的意圖。

## 優先順序

候選主題依下式比較，不虛構搜尋量或難度：

`商業意圖 + 主題相關性 + 本站內容缺口 + 第一手證據 + 內部連結價值 - Cannibalization 風險 - 未確認事實風險`

若同一意圖已有頁面，優先更新既有頁面。新增頁面前必須記錄 Existing-site check、預計 URL 與避免互相競爭的方法。

## 指標

領先指標：每週一次 Run、五個候選、一個選題、一份 Brief、至少一篇經人工確認的新增或實質更新、SEO check 與 production build 通過。

落後指標：非品牌曝光、自然搜尋點擊、開始曝光頁面數、Top 10／Top 20 關鍵字、自然搜尋轉換，以及發布後 7／28／90 天成效。

基準資料未提供前不得宣稱成長百分比。

## 品質與品牌規則

- 觀點必須有具體來源、可驗證材料或經確認的第一手經驗。
- 不為關鍵字犧牲語意、可信度與可讀性。
- 每頁只有一個主要搜尋意圖，標題、H1、metadata 與正文應一致。
- 所有公開內容遵守 `AGENTS.md`、`CLAUDE.md` 與既有寫作規則。
